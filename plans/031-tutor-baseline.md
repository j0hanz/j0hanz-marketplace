## Why this matters

The `tutor` plugin was reset: about 5.8k lines of Python tooling, hooks, templates and README
were deleted, and the plugin now holds only a prose skill (`skills/teach/`, imported from an
upstream "teach" skill). Three leftovers of the old version remain. First, `npm run validate`
still runs the deleted Python test, so the pre-merge gate fails on any machine with Python.
Second, the manifest and catalog still promise "spaced repetition" and a "sealed retrieval
quiz", which the new plugin does not do. Third, there is dead config for the old Python and
template files. After this plan, `npm run check` passes and every description tells the truth.
The plugin also ships to Antigravity CLI, as the maintainer decided. Plans 032–034 build the
new features on this baseline.
