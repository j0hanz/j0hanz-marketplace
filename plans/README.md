## Findings audited but not planned (maintainer's choice, 2026-10-09)

- **Persist `described` across a reload** (`register.tsx:141,205-208`): the module-level map is lost on a hot reload and `tool.describe` fires once per session, so the next `context-<N>.json` under-reports its `tools`. Fix: an atom like `pendingIds`, merged back at `session.start`; or one README Known-limits sentence. Effort S.
- **Reload-path test gaps** (`register.tsx:816-823`, `lib.ts:143-144`): nothing can fail if the reload-restore reads break (folder, turn counter, pending ids; writes are tested, reads are not), and `labelCalls`'s `response: null` and stale `-1` branches have no tests. Fix: extract the restore computation into `lib.ts` and unit-test it, plus two `labelCalls` cases. Effort M.
- **`.gitignore` containing `*` written at the `logDir` root** (`register.tsx:153-158`, `797`): with `logDir` set to `.claude` or `.`, and no `.gitignore` there, git silently ignores new files in that folder. Note the `*` covers git only; a folder synced by other tools (OneDrive, Dropbox) bypasses it. Fix sketch: write the `.gitignore` inside the per-session folder, amend R19 and the README. Effort S.
- **Env-dump and config formats survive field redaction** (`lib.ts:82-86`): `TOKEN=…` dotenv lines, YAML `token: …`, Python-repr dicts and non-string JSON values are not matched (README promises only objects and JSON-text strings). Product call: an anchored line-start rule for the existing field names, effort M with MED false-positive risk given the settled anti-false-positive stance, or one README sentence naming the gap.
- **Investigate `/clear` mid-turn** (`register.tsx:966-984`, `996-1004`): if `/clear` emits no `turn.complete` for the interrupted turn, its buffered records misfile into the first post-clear turn's file and receipt. One live check settles it; fold into the pending live checks below.
- **Catalog and manifest descriptions diverged** (`.claude-plugin/marketplace.json:85` vs `plugins/telltale/.claude-plugin/plugin.json:6`): one-line sync next time either is edited; validate compares only names.
